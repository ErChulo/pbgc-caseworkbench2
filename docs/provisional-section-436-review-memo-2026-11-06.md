# Provisional Section 436 review memo — 2026-11-06

After checking a saved provisional Section 436 preview against its original input, the case output panel can prepare and download an optional UTF-8 plain-text review memo. The memo is explicitly provisional and is **not** an approved memo or final package artifact. Its header and footer state that it is not approval or independent validation. The panel reiterates that facts, rules, citations and review labels are unverified assertions and that the memo may contain case details.

Preparation snapshots both selected files, repeats their case-bound preview verification, and regenerates the evaluation from the original input with the recorded timestamp. The UI compares the rechecked file and preview hashes with the last displayed check. The generated text records the case ID, provisional status and conclusion, plan year, limitation effect, missing facts, blockers, matched rule IDs, all supplied facts and rules, their asserted review statuses and citations, and the evaluation, preview, and input hashes. It displays a separate hash of the exact memo bytes. Values originating in case data are quoted; line controls and invisible format/directional characters are escaped so they cannot inject report headings or reorder displayed text. The memo uses original input values after regeneration, rather than potentially different Unicode representations in the canonically equivalent preview JSON. File and case changes discard pending or prepared memos. The memo stays in memory until downloaded and is limited to 8 MiB.

The hashes show local consistency, not source authenticity, reviewer authority or approval. Regeneration uses the same evaluator, not an independent actuarial validation. A completed status remains provisional. No changes are made to final package readiness; no workspace file is created or linked. This is not a DOCX/PDF template, legal determination, approved interpretation, or evidence of Excel, BCV, ValTool or Runtime execution. The user must apply local controls when storing or sharing downloaded material.
