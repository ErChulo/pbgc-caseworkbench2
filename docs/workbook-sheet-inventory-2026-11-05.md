# Passive workbook sheet inventory — 2026-11-05

The passive workbook parser now records each worksheet's exact name and visibility in its extraction metadata, including worksheets without observed cells. Workbook population profiling uses this inventory instead of guessing that the last N worksheets are hidden. Hidden and very-hidden sheets are represented as hidden; their distinction remains outside the current profile contract. Missing, ambiguous or inconsistent inventory, unknown cells, duplicate physical cell observations and invalid cell addresses block profiling rather than inventing visibility or silently discarding observations. Parser version for successful workbook inspection is now 1.1.0.

Previously persisted extractions without the inventory must be re-inspected; corrected sheet inventory can change the workbook-profile hash and therefore requires the existing approval lineage to be re-evaluated, not carried forward automatically. These changes preserve passive inspection only and do not execute workbook formulas. Population selection/routing, record provenance and workbook release remain blocked as described in `workbook-routing-blockers-2026-11-05.md`.
