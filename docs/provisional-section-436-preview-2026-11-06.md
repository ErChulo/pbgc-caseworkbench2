# Provisional Section 436 preview — 2026-11-06

The case output panel now offers an empty, case-bound JSON input template and an in-memory preview from a user-selected local file. The template contains no facts, rules, or approvals and produces a blocked result until the required facts and rules are supplied. Input is a UTF-8 object with exactly `caseId`, `facts`, and `rules`; fact and rule shapes are checked using the approved Section 436 evaluation contract. The panel lists the contract fields and enum values. It caps the input at 1 MiB, 500 facts, 500 rules, and 4,000 combined fact/rule citations. The generated evaluation must also pass the approved schema, content-hash and same-engine replay checks; an expanded evaluation over the replay check's 1 MiB cap fails closed.

The downloadable, canonical JSON is a **project-specific provisional preview**, not an approved Section 436 evaluation artifact. It wraps the generated evaluation with a provisional kind, explicit limitations, exact input-file SHA-256, and a typed preview-content SHA-256; the UI separately calculates and displays the exact downloaded-byte SHA-256. The preview's input hash is a record of bytes, not proof of their source or authenticity. The preview content hash includes the evaluation's operational metadata; the nested evaluation hash excludes that metadata. No trusted external hash, digital signature, provenance authentication, actuarial review or approval is supplied. Review-status labels in the input are only assertions, and even a `completed` result remains a preview. No final output stage is cleared or linked. A preview wrapper is not accepted directly by the separate evaluation replay panel; that panel accepts evaluation artifacts, not this project-specific wrapper.

Inputs are snapshotted before asynchronous work. Replacing the file or changing the active case discards pending UI results and downloads. Neither input nor preview is persisted in the workspace by this feature; downloaded files can contain case data and need local case-data controls. The browser does not call a server or external model. The feature does not prove citation eligibility, completeness, source authority, rule applicability, actuarial correctness, or authenticated reviewer identity, and it does not execute Excel, BCV, ValTool or Runtime. The evaluator's conservative blocking rules and fixed contract version limitations remain as documented in `section-436-evaluator-guards-2026-11-06.md`.
