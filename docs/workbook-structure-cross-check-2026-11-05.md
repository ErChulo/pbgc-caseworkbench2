# Workbook formula structure cross-check — 2026-11-05

Workbook structural validation now compares formula metadata with actual worksheet cells and output mappings. It rejects missing or changed worksheet formulas, formula cells with simultaneous values, untracked worksheet formulas, invalid or duplicate worksheet addresses, repeated formula IDs and multiple formulas at the same physical target. Physical target identity includes the sheet and normalized address, so the same address on different sheets is not a false duplicate. Formula reachability uses formula IDs rather than accidentally treating an unrelated cell at the same address as reachable. Workbook-scoped names, like sheet-scoped names, must point to an existing sheet. XLSX spec generation also rejects duplicate Excel names in the same scope, including names duplicated across scenarios.

Tests include changed content with the workbook hash recomputed, demonstrating that hash consistency alone is not enough, plus different-sheet address reuse and the named-range cases. The reconciliation fixture was corrected to contain actual formula worksheet cells; it still uses synthetic comparisons only.
