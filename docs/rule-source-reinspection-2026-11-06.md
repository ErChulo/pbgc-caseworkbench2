# Rule source reinspection

The case rule-authoring flow now reopens each selected source from content-addressed storage, checks current case-snapshot membership and exact size and SHA-256, screens binary signatures, re-runs passive inspection and candidate extraction, and requires an exact candidate and an eligible case-evidence authority context. Worked examples and reference-only candidates cannot become primary governing evidence through this path. Architecture proposal building repeats the source check for each rule's primary candidate, so changing source bytes after authoring blocks the next build. A synthetic browser test exercises tampering both before authoring and before building, followed by restoration.

The wizard checks case, workspace, evidence snapshot, review state, catalog and build generation around asynchronous work. It serializes rule authoring and unresolved-item decisions against each other in the current session, blocks a missing selected predecessor instead of silently creating an initial rule, shows save failures, and warns if a record may have been written without its review event. The catalog-current check now compares case-package artifacts separately from bundled reference policy files. The form labels the typed reviewer as locally asserted and does not claim authenticated authority.

These checks do not authenticate identity, authorization, case snapshot, catalog, eligibility, source authority or actuarial interpretation. They do not prove correctness or completeness of passive extraction, assess supporting citations, defend against all hostile OOXML or ZIP inputs, or establish a cross-window transaction. Source inspection is limited to 32 MiB and snapshot members; archive-contained sources can be blocked. A case change or event-write failure can leave a rule record without its event. The existing raw rule log is not restored into the wizard after reload; this change does not repair or authenticate historical records. Previously saved output is not revoked. Release and I/B routing gates remain blocked.
