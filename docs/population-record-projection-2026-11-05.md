# Explicit population record projection — 2026-11-05

Added a domain-level review primitive that takes an explicit source sheet, row, and field-to-column bindings with exact expected headers. It verifies the provided workbook profile against the effective approved profile hash and preserves original row addresses rather than sorting or compacting column values. Sparse missing cells, empty strings, zero, leading zeros, formulas, and cell errors remain distinct; formula cached values are not presented as participant inputs. The projection carries a deterministic content hash and reports whether all selected values are present and non-formula.

Invalid/duplicate source cells, invalid or duplicate bindings, a header mismatch, an invalid row, a missing sheet, a non-approved profile, and profile-hash mismatch fail closed. Tests use synthetic values only and verify row identity and deterministic projection independent of binding order.

This is **not wired into the wizard or workbook generation** and does not lift the population-routing blocker. The caller-supplied decision is not independently authenticated; a profile hash and decision ID are consistency checks, not proof of authority or authorization of the selected person and bindings. A reviewed participant-selection workflow, authenticated decision lineage, field mapping governance, source byte verification, record-to-workbook mapping, B-cell semantics, scenario target layout and end-to-end validation remain needed. No participant data is persisted or sent to any network service by this primitive.
