# Browser checks and architecture UI

A browser review exposed a misleading architecture form: the UI asked the reviewer to select scenarios and tabs and enter approval details, but the orchestrator ignored those inputs. The form has been replaced with a **Build proposed architecture** action. It says explicitly that deterministic rules choose scenarios and tabs and that the action does not record an architecture approval or approve a workbook. Existing legacy selection files are not displayed as evidence of approval. An authenticated architecture-approval workflow remains a future requirement.

The synthetic production-path browser test now exercises intake, source and policy review, case controls, byte-bound population verification, and architecture proposal. Formula approval is now blocked pending real test and oracle references, superseding the earlier four synthetic decisions; see `formula-evidence-blocker-2026-11-06.md`. The test verifies that modified preserved workbook bytes block a subsequent build and that withdrawing the population decision clears the in-memory architecture. A stale case-creation text locator was also corrected. No real participant data or actual human approval was used.

For browser execution in this sandbox, Chromium 138 and its matching shared libraries were unpacked from the npm `@sparticuz/chromium@138.0.2` package into an external temporary workspace. The repository dependencies were not changed. In a separate repository copy with the newly generated single HTML artifact, all 55 Chromium Playwright tests passed. The suite includes direct `file://` tests and offline/request-blocking checks; it uses synthetic workspaces and fixtures, not a live PBGC environment. It does not demonstrate Microsoft Edge behavior, real user authorization, Excel calculation, actuarial validation, or production readiness. The regular test suite remains blocked by the unavailable approved Data Dictionary Git LFS object. The separately generated standalone artifact was verified; the user's pre-existing modified tracked `dist` file was not replaced.
