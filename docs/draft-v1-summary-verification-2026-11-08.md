# Draft V1 summary generation and restoration — 2026-11-08

A functional defect prevented many draft V1 summaries from being saved: the approved reference index includes empty field-name placeholders, while the draft schema requires every field-preview item to be nonempty. The generator now omits empty placeholders from the first 50 preview entries without changing the reference index, its recorded hashes, reference matching, or the relative order of the remaining entries. Outputs that were already schema-valid are unchanged by this correction; previously invalid drafts must be regenerated. The governed schema fixes the generator version string, so it was not silently changed. The generated summary remains blocked and is not a workbook or an approval.

Draft creation now bounds R5 input at 8 MiB, suppresses stale responses across case/workspace changes, serializes same-session draft saves, verifies the generated case/contract/content hash, rereads the saved bytes before recording the event, and reports possible partial writes. Restoration bounds files at 4 MiB and checks case, approved contract and deterministic content hash before display. Older invalid, mismatched or tampered artifacts are ignored, not repaired. The hash excludes operational metadata and is a consistency check only; the selected R5 bytes are not retained by this feature, and these checks do not prove source authority, derivation, reviewer authority, independent validation, or final-package readiness. Concurrent changes in another browser window and in-flight writes remain non-transactional.

Synthetic unit tests generated contract-valid blocked drafts for all 247 indexed references and tested altered payloads, case mismatches, input snapshots and bounded reads. Chromium tests covered generation, restoration, tampering, post-write mutation and a case switch during a delayed input read; a synthetic built-file generation ran with HTTP blocked and an in-memory workspace. Typecheck, lint, format, schema and contract checks passed; an isolated single-file build and verifier passed. The full suite reported 1,199 passed, four skipped and one failed Data Dictionary suite due to missing approved Git LFS bytes. No real case data, native office workspace, external Excel execution or human approval was used. Vite still reports the existing browser-externalized Node module warning.
