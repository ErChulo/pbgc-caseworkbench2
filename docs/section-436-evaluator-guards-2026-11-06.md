# Section 436 evaluator safeguards — 2026-11-06

The existing Section 436 evaluator is a deterministic domain component, not a complete production case workflow. It previously selected the first approved fact even if another value was present, selected equal-priority conflicting matches by rule ID, accepted JavaScript numeric syntaxes as decimals, and did not check rule effective dates. It could also mark an explicit additional-review conclusion completed and froze caller-owned input objects.

The evaluator now blocks duplicate required facts (including provisional alternatives), duplicate rule IDs, invalid required value kinds, malformed citation details, invalid rule metadata, reversed plan-year boundaries, and invalid effective dates. It conservatively blocks if a supplied rule takes effect after the start of the plan year, because this model does not specify how to evaluate a midyear change. Equal-priority matching rules with different conclusions or limitation effects block while retaining matched rule IDs and citations. Different explicit priorities still determine order; a matching rule requiring additional review is inconclusive. Bounded plain decimal strings are compared exactly using integer arithmetic, rather than binary floating point. Inputs are snapshotted before hashing and freezing.

These are conservative checks, not a Section 436 legal or actuarial policy. An earlier effective date alone does not prove applicability, currency, source eligibility, reviewer authority, or absence of supersession. Citations and approval labels are locally asserted, not authenticated or verified against case evidence. Further governed rules and source/approval verification are required. No official thresholds, certification-date assumptions, percent ranges, or midyear interpretation were invented. The contract fixes `engineVersion` at `section-436-evaluator-v1.0.0`; versioning the changed evaluator requires approved contract governance rather than silently modifying the schema. The evaluator is not a completed memo, external execution, or approval.
