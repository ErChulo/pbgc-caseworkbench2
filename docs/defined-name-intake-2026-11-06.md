# Passive defined-name intake — 2026-11-06

Workbook inspection previously discarded defined names, so a workbook could reach architecture selection without an observed name. Parser version 1.2.0 records the source definitions and scope indices as passive extraction metadata. Population profiling accepts only unambiguous single-cell definitions targeting observed cells, with local scope on the target sheet; it preserves workbook versus sheet scope and quoted sheet names. The wizard includes these observations in the profile hash and passes them to architecture selection. No names, formulas or links are executed.

The current architecture model cannot represent range-valued names, expressions, external references, names pointing at unobserved cells, or sheet-scoped names targeting another sheet. Such workbooks now block population profiling rather than silently losing definitions. Empty, malformed, ambiguous, duplicate or missing definition inventories also block. These restrictions can block common workbook features such as print areas; supporting them requires an approved model and review, not an inferred single-cell substitute.

Workbook candidate detector version 1.1.0 prevents an older candidate approval from automatically transferring to a newly inspected profile. The wizard preserves candidates from the same source artifact rather than discarding prior review history. It blocks approval of a blocked or legacy workbook profile and blocks architecture generation when an approved legacy workbook lacks a defined-name inventory; old decisions may still be revoked or superseded. A re-inspected candidate needs its own review. These consistency checks are not reviewer authentication or approval authority.
