## Protocol Summary

**Objective:** Validate that authorized caseworkers can complete core intake and evidence-review tasks on first attempt without task-specific coaching.

**Population:** At least 20 authorized caseworkers representing intake and evidence-review roles.

**Procedure:**
1. Participant receives the approved operator guide and built-in help access.
2. Timed attempt begins; no task-specific coaching is permitted after start.
3. Participant completes all four required tasks on first attempt.
4. Moderator records completion, errors, elapsed time, and assistance used.

**Four Required Tasks:**
1. Create a synthetic case using the authoritative PBGC case identifier
2. Submit the supplied mixed synthetic package
3. Identify every quarantined artifact
4. Locate every unresolved item

**Success Definition:** All four tasks completed without a critical error.
