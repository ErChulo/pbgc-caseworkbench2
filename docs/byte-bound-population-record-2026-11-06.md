# Byte-bound population record review primitive — 2026-11-06

Added a local adapter that snapshots the supplied workbook bytes and review inputs, checks their SHA-256 against the candidate artifact, validates candidate/evidence consistency, passively re-inspects the bytes and names, recomputes the workbook-profile hash, replays the decision chain, and projects an explicitly selected row and exact header bindings. Changed bytes, missing or mismatched evidence, blocked inspection, stale or revoked decisions, and invalid selected headers fail closed. Formula cached values are not treated as participant inputs. Tests use synthetic workbook content only.

This is a **review primitive**, not a production routing authorization. It is not wired into the wizard or workbook generation; the I/B routing blocker remains. Candidate and decision hashes are not signatures; the supplied reviewer identity and authority, source eligibility and quarantine release, participant selection and field bindings still require authenticated, case-scoped governance. Evidence referring to a different artifact is rejected by this limited primitive. It does not establish actuarial correctness or approve output. The build tree-shakes this unused primitive until a governed workflow adopts it.
