# Browser feasibility spike

This Phase 1 spike exercises only the delivery and browser-security boundary. It does not ingest evidence or participant data.

Run `npm run build`, `npm run verify:single-file`, and `npm run test:browser:chromium`. Run the full `npm run test:browser:e2e` only where both configured Chromium and Edge executables are installed. Results and the production go/no-go decision are recorded in `docs/feature-009-browser-feasibility.md`.
